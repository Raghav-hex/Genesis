## Excluded private artwork
Mossy Cavern-derived WebP files are intentionally not included in this public repository because the source asset license prohibits repackaging or redistribution, including modified derivatives. The public build uses procedural scenery fallbacks and requires no remote asset URLs.

## Runtime
All bundled image assets are local. No CDN or runtime asset downloads are needed.
